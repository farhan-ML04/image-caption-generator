# 🧠 Image Caption Generator (CNN + LSTM)

## 🚀 Overview

An end-to-end deep learning project that generates captions for images by combining **Computer Vision (CNN - VGG16)** and **Natural Language Processing (LSTM)**.

---

## ⚙️ Pipeline

* Extract image features using **VGG16**
* Clean & tokenize captions (`startseq`, `endseq`)
* Train **LSTM model** for sequence prediction
* Generate captions word-by-word

---

## 📊 Evaluation

* BLEU Score (BLEU-1, BLEU-2) used to measure caption quality

---

## 🖼️ Sample Output


```
group of people are gathered around in the dark
```
